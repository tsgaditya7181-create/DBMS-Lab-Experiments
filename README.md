# DBMS-Lab-Experiments
# DBMS Experiment 3

## Aim
To create an Employee-Department-Project database schema and execute SQL queries demonstrating selection, projection, aggregation, GROUP BY, HAVING, CASE expressions, and ORDER BY.

## Technologies Used
- SQL
- MySQL
- Database Management System (DBMS)

## Source Code
The SQL source code is available here:

[View SQL Source Code](./experiment3.sql)

## SQL Queries Performed

1. Selection – Display employees with salary greater than 70000.
2. Projection – Display employee names and salaries.
3. Aggregation – Count employees and calculate average salary.
4. GROUP BY and HAVING – Display departments having more than 5 employees.
5. CASE Expression – Classify employees according to salary.
6. ORDER BY – Display employees in descending order of salary.
